# NextReport: 30-day social launch pack

Prepared 16 November 2026. Default calendar: 17 November–16 December 2026.

## Download from GitHub

1. Open either file below while signed into the GitHub account with access to this repository.
2. Click **Download raw file** (the downward-arrow icon in the file toolbar). GitHub may also show **View raw** or a download link for binary files.
3. Save the file to your computer. Extract the ZIP before opening the graphics or CSVs.

- [Excel workbook](NextReport_30_Day_Social_Plan.xlsx)
- [Complete ZIP: Excel, six CSV files, 60 graphics, preview and instructions](NextReport_30_Day_Launch_Pack.zip)

Open **START HERE** in the workbook. The five platform tabs contain 30 posts each: LinkedIn, Facebook, Instagram, X and Reddit. The combined calendar repeats those same 150 posts for filtering. The workbook also includes daily actions, guidance, source notes, experiments, reply templates and a results tracker.

Change cell B4 in START HERE to shift workbook dates. CSV dates remain fixed. Times are IST (Asia/Kolkata) with UTC equivalents. CSVs are reference/copy-paste exports, not certified Zoho bulk-upload templates.

Schedule the first seven days and review before queuing more. Instagram requires a media attachment and uses the fixed bio link for clicks. Reddit drafts require manual community-rules checks: post only where permitted, adapt into a relevant answer, or skip. RD-20 and RD-30 need approved product-feedback/showcase placement. No links or branded graphics on Reddit.

These are planning assets only. No posts have been scheduled or published. No application code is changed by this directory. You do not need to merge a PR to download files from its branch.
